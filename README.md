#Fit-Log

#FitLog is a modern, responsive workout management web application built with Next.js and TypeScript. 

#Technologies Used
1.Next.js
2. React
3. TypeScript
4. Tailwind CSS
5.DaisyUI
6.React Icons
7.React Toastify
8.Context Api
9.Git & GitHub

#Key Features
1.Workout Library
2.Today's Workout Plan
3.Save Workouts
4.Workout Tracking
5.Workout Details
